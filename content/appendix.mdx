<h3 className="ch-title" style={{fontSize: '1.25rem'}}>A. Reproducibility &amp; Commands</h3>
</div>
<div className="prose rv d2">
  To reproduce the unlearning ensemble results, clone the repository and fetch the surrogate celestial dataset. The script requires Python 3.10+ and a CUDA-enabled GPU (minimum 8GB VRAM).
</div>
<div className="figure rv d2">
<div className="fig-panel">
```bash
# 1. Environment Setup
git clone https://github.com/praneetgogoi/Neural-debris-removal.git
cd Neural-debris-removal
pip install -r requirements.txt

# 2. Fetch the synthetic sky dataset (simulated streaks & patches)
python scripts/fetch_dataset.py --set train_v2

# 3. Run the defense pipeline (Committee size: 4)
python train.py --defense ewc --committee_size 4 --lr_search_space "0.001,0.005,0.01"
```
